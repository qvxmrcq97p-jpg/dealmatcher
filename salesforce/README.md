# Salesforce Metadata — Home Page Layout

This directory holds Salesforce metadata for the `Getting Started Home`
Lightning Home Page. It replaces the manual click-through in Lightning
App Builder with a one-shot deploy.

## What's here

- `flexipages/Getting_Started_Home.flexipage-meta.xml` — the Home Page
  layout: a `flexipage:tabset` with one tab per dashboard (9 total
  by default). Edit `tools/fetch_home_dashboards.py` to add/remove
  dashboards from the layout.
- `package.xml` — Metadata API deployment manifest.
- `DASHBOARD_REFERENCE.md` — auto-generated lookup table of dashboard
  titles → DeveloperNames → IDs. Used as the fallback if the XML deploy
  fails and you want to add the dashboards via the App Builder UI.

## How it's built

The XML is auto-generated by querying the 9 dashboards from Salesforce
(by Title) and templating them into a Tabs layout. Re-run the build
any time the list of dashboards changes:

```bash
cd ~/dealmatcher
python3 tools/fetch_home_dashboards.py
```

To change which dashboards are on the home page, edit the
`WANTED_TITLES` list in `tools/fetch_home_dashboards.py`, re-run the
script, and re-deploy.

## Deploy via Workbench (recommended — no CLI needed)

1. Run the build:
   ```bash
   cd ~/dealmatcher
   python3 tools/fetch_home_dashboards.py
   ```
2. Zip the deployment package:
   ```bash
   cd ~/dealmatcher/salesforce
   zip -r home_page_deploy.zip package.xml flexipages/
   ```
3. Open https://workbench.developerforce.com — log in as
   info@johnsonbuys.com (use Production environment).
4. **migration → Deploy** → choose `home_page_deploy.zip` →
   check **"Single Package"** and **"Rollback on Error"** → **Next**.
5. Click **Deploy**. Wait ~30 seconds. You'll see "Succeeded" when
   the FlexiPage replaces the existing one.
6. Refresh `https://johnsonshomes2.lightning.force.com/lightning/page/home`
   — the home page now shows 9 dashboard tabs.

## Deploy via Salesforce CLI (alternative)

If you have the `sf` CLI authenticated:

```bash
cd ~/dealmatcher
python3 tools/fetch_home_dashboards.py
sf project deploy start \
    --metadata-dir salesforce \
    --target-org info@johnsonbuys.com
```

## Fallback — UI clicks

If the metadata deploy errors out (Salesforce FlexiPage XML is
version-finicky), open `DASHBOARD_REFERENCE.md` and follow the
checklist: it has the exact dashboard titles + DeveloperNames to
type into the App Builder dropdown for each Dashboard component.

## Notes

- The FlexiPage type is `HomePage`. Salesforce will replace the
  current "Getting Started Home" definition with the deployed one.
  The page is already set as the org default, so no activation step
  is required after deploy.
- If you previously added Dashboard components via the UI (4 are
  already in there), this deploy **replaces** the entire layout
  with the Tabs version. Your existing layout is overwritten.
- The default tab is the first one in `WANTED_TITLES`
  (currently `01 Daily Lead Inflow`). Change the order in that list
  to change which tab is active on home page load.
